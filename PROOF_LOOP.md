# Proof loop — psychemap

## Hypothesis
People exploring consciousness topics want rigor and mystery in one view, with clear evidence labels.

## Fastest test (30 min)
1. Run `pnpm dev`, open `/map`.
2. Map one question end-to-end.
3. Ask one person: "Did the evidence labels help you trust what you were reading?"

## Success signal
- User completes map flow without confusion.
- User can explain what "evidence level" means on the result page.

## Fail signal
- User thinks outputs are peer-reviewed fact without reading labels.
- Map result feels generic or empty.

## Claim labels
- **PROVEN:** `pnpm build` passes; routes exist in repo.
- **DEMO:** Map content from sample/local generation.
- **HYPOTHESIS:** Paid plans and retention.
